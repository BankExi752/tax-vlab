# 金税四期下“业—票—税—信”多源异构数据耦合推演与合规裁量虚拟仿真实验

2026 中国仿真创新应用大赛 · 仿真教学创新设计方向（Streamlit 教学应用 V1.0）

依据《税法虚拟仿真实验项目计划书_最终版_V5.2》实现：

- **19 个交互节点**（S1—S19）：案例认领 → 理论快测 → 发票查验（P 指标）→ 四流校验 →
  四税申报 → 风险研判 → 筹划与合规判定 → 双角色对抗 → 定性裁量 → 报告与反馈；
- **四税联动算账闭环**：增值税（一般 vs 小规模）、消费税（成套 vs 拆分）、
  企业所得税（捐赠分年扣除）、个人所得税（年终奖拆分博弈）；
- **核心指标**：凭证可信度 P、进销匹配率、税负率、证据链闭合度、稽查风险条、纳税信用分；
- **规则引擎定性**：无问题 / 一般违规 / 偷税，参数扰动随机种子驱动三类结局；
- **成绩评定**：实验操作 60% + 报告与理论测评 30% + 综合考核 10%，19 步满分 173 分。

## 本地运行

```bash
pip install -r requirements.txt
streamlit run main_app.py
```

## 部署

- GitHub 仓库（Streamlit Cloud 自动部署绑定 main 分支）。
- 依赖仅 streamlit + pandas，无外部模型依赖；合规判定由规则引擎给出，教师端兜底。

## 结构

- `main_app.py`：单文件应用（引擎层纯函数 + 19 步 UI + 报告/结算）
- `requirements.txt`：运行依赖
